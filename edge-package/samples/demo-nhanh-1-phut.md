# Demo nhanh 1 phút

Bài rất ngắn để thử đủ: dải dưới, thẻ giữa, 3 kiểu câu hỏi và bảng kết quả, chỉ trong khoảng một phút.

<lesson time="3s" title="Xin chào" size="banner">
Đây là **dải thông báo**. Bấm *Đã hiểu* hoặc `Enter`. Kéo phần đầu khung để dời, kéo ==góc dưới phải== để đổi kích thước.
</lesson>

<lesson time="12s" title="Thẻ bài học" priority="1">
## Ba điều cần nhớ

1. Bài học hiện theo **mốc thời gian** của video
2. Phím `1`–`9` chọn đáp án, `Enter` đi tiếp
3. Phím `[` và `]` để về bài trước / sang bài sau
</lesson>

<quiz priority="1">
Phím nào chuyển sang bài sau?
- [ ] `[`
- [x] `]`
- [ ] `Esc`
> `]` sang bài sau, `[` về bài trước.
</quiz>

<quiz time="30s" type="multi" priority="1">
Chọn **hai** cách dời hoặc đổi kích thước khung:
- [x] Kéo phần đầu khung
- [x] Kéo góc dưới phải
- [ ] Tua video
> Kéo đầu khung để dời, kéo góc để đổi kích thước. Nhấp đúp để trả về mặc định.
</quiz>
